🗄️ Relational 3NF Architecture

Normalized SQLite schema separating credential authentication from profile details, enrollments, course assignments, and anonymous feedback.

USERS (id, email, password_hash, role) ├── STUDENTS (user_id, student_number, full_name) └── FACULTY (user_id, full_name, department) COURSES (id, code, title, credits) ├── STUDENT_COURSES (student_id, course_id, semester) └── COURSE_ASSIGNMENTS (faculty_id, course_id, semester) FEEDBACK (id, student_id, course_id, assignment_id, semester, content_rating, teaching_rating, overall_rating, comments, created_at) └── UNIQUE(student_id, course_id, semester)

🔒 Anonymity & Security Model

Engineered with strict separation of duties to ensure student privacy while maintaining database referential integrity.

1. Faculty Privacy: Queries join through COURSE_ASSIGNMENTS and omit STUDENT_ID from SELECT clauses. 2. Werkzeug Password Hashing: PBKDF2/Scrypt salting ensures credentials are never stored in plaintext. 3. Duplicate Prevention: UNIQUE(student_id, course_id, semester) constraint prevents duplicate entries. 4. CSRF Protection: Flask-WTF signed session tokens on POST.

💻 1. Run Locally (Windows PowerShell)

Clone the repository and run the Flask development server in a few steps:

git clone https://github.com/AshishForCode/feedback-management.git cd feedback-management python -m venv .venv .\.venv\Scripts\Activate.ps1 pip install -r requirements.txt $env:SECRET_KEY = "dev-secret-key-123" python run.py

The repository includes render.yaml and Procfile for instant deployment:

1. Push your repo to GitHub (Done!) 2. Go to https://dashboard.render.com 3. Click "New +" -> "Web Service" 4. Connect "AshishForCode/feedback-management" 5. Set: - Environment: Python 3 - Build Command: pip install -r requirements.txt - Start Command: gunicorn run:app 6. Hit Deploy!
